# Beacon CNN Training

The CNN ranks candidate blobs; the Kalman tracker still owns trajectory
continuity. Training examples are generated by the existing `sim/` and
`disturbance/` modules, including primary beacons, distractors, noise, blur,
exposure variation, and sub-pixel shifts.

```powershell
.\venv\Scripts\pip.exe install -r requirements-training.txt
.\venv\Scripts\python.exe -m training.generate_dataset
.\venv\Scripts\python.exe -m training.train_classifier --epochs 10
```

The trainer writes `tracking/model.onnx` for application inference and
`tracking/model.pt` as a training checkpoint. Restart the application after
exporting a new model. Increase dataset diversity before increasing epochs;
real false-positive crops from failed videos are the most useful hard negatives.
